# Scranly

Taking my weight loss, fitness, and diet goals seriously — and after finding too
many apps I'd have to pay for, I decided to build my own. I've been doing this
for too long to just let it go. Meet Scranly 🥗🏃‍♂️ — the name might change later
though 😅. Building this for self.

Free, no ads, no subscription. Invite-only to start.

A React Native app, bare CLI. The decisions behind it are recorded as ADRs in
[`docs/adr`](docs/adr) — the daily targets, navigation without a tab bar, which
libraries read a barcode and a label, and what is still open.
